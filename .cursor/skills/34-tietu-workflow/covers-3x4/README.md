# 3:4 封面模板（随本 skill 分发）

> 视频号 / 小红书 · **3:4（1080×1440）**  
> 布局 DNA 锁定：居中、两边留空、大标题最多两行。

机器可读：`style-catalog.json`  
样式：`covers.css` + `templates/`  
截图：`render_cover.py`  
成片第一帧：`../scripts/prepend_cover_frame.py`

## 布局 DNA（勿改 CSS 核心变量）

| 项 | 标准 |
|---|---|
| 对齐 | 全部居中 |
| 两边留空 | 左右约 120px；标题块 max-width ≈ 820px |
| 大标题 | **最多两行**；4 字行约 160–172px |
| 系列标 | 轻量青/橙字，勿厚边框胶囊 |
| 底 | 深色 + 底部暖橙光晕 |
| 品牌 | 沉底「汪斌带你开公司」 |

## 七套封面池（默认加权抽签，常换）

| id | 风格 |
|---|---|
| `1` / `1b` | 暗底 + 青系列标 + 居中大白字 |
| `2` | 暗底 + 橙系列标 + 居中大字 |
| `3` | 大字 + 图表剪影 |
| `4` | 痛点钩子（白字+红强调，**降权，勿每次默认**） |
| `5` | 奶油浅底 + 深墨大字 |
| `6` | 亮色 Mesh 浅底 + 深墨大字 |

`--style` 留空：按文件夹名稳定抽签。Agent **禁止**每套都写 `--style 4`。

## 禁止

- 主标题贴边撑满 / 三行及以上
- 左栏小字缩角落
- 未改文案就改 `--safe-x` / `--title-max` / 标题字号档
