# 主题 G：丝网海报（Screen Print）

> 成型样例：`workspace/HTMLcards/上滑_2026-09-19_什么是销售费用（海报）/`  
> 3:4 贴图 CSS：`references/theme-g.css` · 长卷 CSS：`34-eli5-scroll/references/theme-g-long.css`

## 风格定位

海报纸底 + 靛蓝/朱红丝网叠色 + 粗黑描边 + 色块硬投影。  
像印厂刚拉出来的宣传海报，不是玻璃、Mesh、奶油、蓝图、墨纸、石板。

## 字体（七套共用）

## 封面

浅色封面池 `5 / 6` 或带冲击色的暗底均可；与朱红/靛蓝海报配。

## 与 C / E 的区别

| | C 奶油刊物 | E 墨纸朱印 | G 丝网海报 |
|---|---|---|---|
| 底 | 暖奶油柔和 | 冷灰纸 | 海报米色 + 斜纹 |
| 强调 | 陶土橙 | 朱砂印 | 朱红 + 靛蓝双印 |
| 形 | 圆角白卡 | 直角硬投影墨线 | 粗描边 + 色块错位投影 |
