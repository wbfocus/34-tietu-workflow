# 主题 E：墨纸朱印（Ink Seal）

> 成型样例：本集 `workspace/HTMLcards/上滑_2026-09-19_如何管好应收账款（墨纸）/`  
> 3:4 贴图 CSS：`references/theme-e.css` · 长卷 CSS：`34-eli5-scroll/references/theme-e-long.css`

## 风格定位

冷灰纸底 + 墨线直角卡 + 朱砂印强调 + 硬投影。  
像账本边角盖了章，不是玻璃、不是 Mesh、不是奶油、不是蓝图网格。

## 字体（五套共用）

见 [type-shared.md](type-shared.md)。主题 E：

| 类 | 色 |
|---|---|
| `.mark` | `#C23A2F`（朱砂） |
| `.mark-sage` | `#2F5D50`（墨绿） |

## 版式

共用 [layout-shared.md](layout-shared.md)。本主题：**直角**（`border-radius: 0`）、墨线描边、轻硬阴影 `3px 3px 0`。  
可选用 `.seal-corner` 朱印角标；原则框可有「印」字圆环装饰。

| 角色类 | 本主题色 |
|---|---|
| `.terra` | `#C23A2F` |
| `.sage` | `#2F5D50` |
| `.ochre` | `#8B6914` |

## 封面

浅色封面池 `5 / 6` 或暗底均可；标题偏痛点问句时可考虑 `4`，但不要套套都用 4。

## 与 C / D 的区别

| | C 奶油刊物 | D 工程蓝图 | E 墨纸朱印 |
|---|---|---|---|
| 底 | 暖奶油圆角 | 藏蓝网格 | 冷灰纸直角 |
| 强调 | 陶土橙 | 图纸黄/青 | 朱砂红 |
| 形 | 柔和圆角白卡 | 青描边小圆角 | 墨线 + 硬投影 + 印章 |
