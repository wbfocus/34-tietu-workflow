# 主题 I：货柜码头（Cargo Dock）

> 成型样例：`workspace/HTMLcards/上滑_2026-09-19_买的没有卖的精如何优化采购（货柜）/`  
> 3:4 贴图 CSS：`references/theme-i.css` · 长卷 CSS：`34-eli5-scroll/references/theme-i-long.css`

## 风格定位

港湾深蓝底 + 集装箱橙 / 海绿 / 吊机黄条纹 + 直角货柜卡。  
像码头堆场，不是地铁导视、不是石板粉笔、不是丝网海报。

## 字体（九套共用）

见 [type-shared.md](type-shared.md)。主题 I：

|---|---|
| `.mark` | `#F97316`（集装箱橙） |
| `.mark-sage` | `#2DD4BF`（海绿） |

## 版式

共用 [layout-shared.md](layout-shared.md)。本主题：直角货柜感、左色条、少圆角。

## 文件夹后缀

`（货柜）` — 例：`上滑_2026-09-19_买的没有卖的精如何优化采购（货柜）`

## 封面

优先暗底货柜感 `7`，或港湾浅底 `8`；也可暗底 `1/1b/2`。禁止连着几期都用 `4`。

## 与 F / H 的区别

| | F 石板粉笔 | H 地铁线路 | I 货柜码头 |
|---|---|---|---|
| 底 | 深绿石板 | 浅灰导视 | 港湾深蓝 |
| 形 | 粉笔方块 | 圆站点 | 直角货柜 + 色条 |
| 强调 | 粉笔黄 | 红/蓝/青绿多线 | 橙/海绿/吊机黄 |
