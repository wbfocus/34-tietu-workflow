# 主题 D：工程蓝图（Blueprint）

> 成型样例：`workspace/HTMLcards/上滑_2026-09-19_企业经营就三件事（蓝图）/`（长图上滑）  
> 3:4 贴图 CSS：`references/theme-d.css` · 长卷 CSS：`34-eli5-scroll/references/theme-d-long.css`

## 风格定位

藏蓝工程图纸底 + 浅青网格 + 青线描边卡片 + 黄高亮重点 + 四角准星。  
**不是**深色玻璃（A）、亮色 Mesh（B）、奶油刊物（C）。适合流程、拆解、总纲、「看穿一层」类内容。

## 字体（四套共用）

| `.mark-sage` | `#7DFFC4` |

## 版式（共用骨架，本主题只换外壳）

见 [layout-shared.md](layout-shared.md)。页眉方标 + 英文小标 + 巨号水印 + `.c-foot` + 六种节奏。  
角色色在本主题里改映射：

| 角色类 | 本主题色 | 用途 |
|---|---|---|
| `.terra` | `#5EC8FF` | 主结构方标 / 点号 |
| `.sage` | `#7DFFC4` | 通过 / 正向 |
| `.ochre` | `#FFE566` | 提醒 / 原则边 |

长卷可加四角 `.bp-cross.tl|tr|bl|br`（准星），氛围层用青光晕，**不要**玻璃模糊、不要奶油白卡、不要暖 Mesh。

## 氛围层

- 上滑：`.atm` 青/绿径向光 + 轻噪点；网格画在 `.phone` 背景上。
- 3:4 贴图：全卡网格或淡青光晕 ≤2；**禁止**再切 200–300px 顶区。
- 卡片：**直角感**（`border-radius: 4px` 左右），虚线原则框用黄边，不用橙色虚线。

## 文件夹后缀

`（蓝图）` — 例：`上滑_2026-09-19_企业经营就三件事（蓝图）`

## 封面

暗底封面池 `1 / 1b / 2 / 3` 优先；与蓝图长卷配。不要默认痛点红字 `4`。

## 与 A 的区别（防写串）

| | A 深色玻璃 | D 工程蓝图 |
|---|---|---|
| 底 | 近黑 `#0a0f1a` + 玻璃模糊 | 藏蓝 `#0A2342` + 网格 |
| 强调 | 品牌橙 `#FF7700` | 图纸黄 `#FFE566` |
| 卡片 | 圆角大、backdrop-blur | 小圆角、青描边、无模糊 |
| 装饰 | 光晕球 | 四角准星 + 虚线环 |
