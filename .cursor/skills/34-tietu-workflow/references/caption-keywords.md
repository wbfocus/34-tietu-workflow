# 配套文案与关键词写法

参考样本：`HTMLcards/038、财务分析必备的40个指标/文案.txt`。

出图流程跑完之后，为这一整套卡片写一份 `配套文案与关键词.md`，结构固定为三块：

## 1. 发布文案（正文）

结构（对照样本）：

```text
<一句钩子/反差观点，点出常见误区或痛点>
<一句承接，介绍这套卡片解决什么，语气延续"老汪"人设>
<分要点罗列，每条一个 emoji + 关键词 + 一句解释，对应卡片里的每个内容页维度/步骤>
<一句总结句，呼应封面的数字冲击或核心主张>
<结尾转化话术：延续原文档里出现的具体动作（回复关键词/加微信/后台私信），没写清楚就用更通用但不编造联系方式的说法，例如"感兴趣的话后台聊">
```

- 字数：150~300 字，公众号/小红书正文体量，不要写成长文。
- 每个 emoji 要点尽量和卡片内容页一一对应，方便用户发图文时文案与配图能对上号。
- 不要在文案里出现内部代称（分镜表、design-system 等），只写用户/读者视角的话。

## 2. 关键词 / 话题标签

- 5~8 个，`#关键词` 格式，一行内用空格隔开（对照样本 `#财务分析 #制造业财务 #业财融合 #管理会计 #经营分析`）。
- 覆盖：行业词（如"制造业财务"）、方法论词（如"业财融合"）、场景词（如"经营分析"）、平台热词（可选，如小红书常见的"干货"、"职场"类标签，仅在内容匹配时加）。
- 不要堆砌无关热门标签蹭流量，只放和这套卡片真实相关的词。

## 3. 用途备注（可选，一两行）

简单写一句这套卡片适合发在哪（小红书图文 / 公众号知识卡 / 朋友圈九宫格等），方便用户直接判断怎么用，不用展开讲运营策略。

## 文件格式示例

```markdown
# 配套文案与关键词

## 发布文案

<正文...>

## 关键词

#xxx #xxx #xxx #xxx #xxx

## 备注

适合发小红书图文卡 / 公众号知识卡合集。
```
