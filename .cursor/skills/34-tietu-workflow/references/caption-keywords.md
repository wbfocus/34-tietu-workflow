# 配套文案与关键词写法

参考样本：`examples/gold-a-ceo-star-dark/配套文案与关键词.md`。

出图 / 出片跑完之后，为这一套写一份 `配套文案与关键词.md`。  
**轮播 / 橱窗 / 上滑都要写**；上滑成片后这是必做工序，不能漏。

写之前必读 `workspace/corrections/订正流水账.md`；短标题和关键词都用人话（会上能说出口），禁止黑话当标题。

---

## 上滑视频（默认结构 · 先写这块）

成片看完画面后提炼，文件里至少有两块：

### A. 短标题（备选 5～8 条）

- 每条像人说话：一句痛点 / 一句主张 / 封面大字变体均可。
- 禁止两个字概念名单独当标题（如「口径」「三算」）。
- 用户发视频号、抖音、朋友圈时从里面选一条。

### B. 关键词（分 3～4 组）

每组一行，`#词` 空格隔开：

| 组 | 放什么 |
|---|---|
| 组1 岗位/主题 | 如 `#财务BP #业财融合` |
| 组2 痛点/钩子 | 如 `#记账 #拍板 #管报` |
| 组3 场景 | 如 `#产品赚钱表 #合同评审` |
| 组4 平台可选 | 如 `#职场干货`（仅内容真相关才加） |

发一条时：**1 个短标题 + 组1 + 另组里挑 2～3 个**，不要四组全贴。

### C. 一句话发布文案（可选）

2～4 句钩子即可；上滑可不写长文。

```markdown
# 配套文案与关键词 · <标题>

## 短标题（备选）

1. …
2. …

## 关键词（几组）

**组1 · …**  
#… #…

**组2 · …**  
#… #…

## 一句话发布文案（可选）

…

## 备注

- 成片文件名
- 适合发哪
```

## 轮播 / 橱窗贴图（可写完整发布文案）

结构仍可为三块：

### 1. 发布文案（正文）

```text
<一句钩子/反差观点，点出常见误区或痛点>
<一句承接，介绍这套卡片解决什么，语气延续"老汪"人设>
<分要点罗列，每条一个 emoji + 关键词 + 一句解释，对应卡片里的每个内容页维度/步骤>
<一句总结句，呼应封面的数字冲击或核心主张>
<结尾转化话术：延续原文档里出现的具体动作（回复关键词/加微信/后台私信），没写清楚就用更通用但不编造联系方式的说法，例如"感兴趣的话后台聊">
```

- 字数：150~300 字，不要写成长文。
- 不要在文案里出现内部代称（分镜表、design-system 等）。

### 2. 关键词 / 话题标签

- 也可按上面「几组」来写；至少 5～8 个 `#关键词`。
- 不要堆砌无关热门标签。

### 3. 用途备注（可选）

小红书图文 / 公众号知识卡 / 朋友圈九宫格等，一两行即可。
