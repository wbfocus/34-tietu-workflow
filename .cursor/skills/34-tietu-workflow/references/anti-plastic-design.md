# 反塑料感设计规范（贴图 / 配图通用）

> 提炼自「受够了 AI 网页的塑料感」方法论（frontend-design、taste-skill、impeccable、Awesome Design.md），**适配静态 HTML 截图卡片**（无 JS 动效）。

写每一张卡之前读本节；出图前跑一遍文末 QA。

---

## 一、塑料感从哪来（必须主动打破）

| AI 通病 | 本工作流的反制 |
|---|---|
| 紫蓝渐变糊一脸 | **禁用**紫/靛大面积渐变；老汪品牌只用天蓝 `#0EA5E9` + 亮橙 `#FF7700` |
| Inter / Roboto / Arial 万能字 | **禁用**作结构字；用 HarmonyOS Bold + 霞鹜文楷 +（可选）ZCOOL XiaoWei |
| 左右对称三列排排坐 | 每套图至少 **2 张**用不对称版式（错位、左重右轻、宽窄不一） |
| 每张卡长得一模一样 | 封面冲击 / 内页清单 / 结尾 CTA **版式要有节奏变化** |
| 毛玻璃 + 大光晕堆满 | 背景层 ≤2 个光晕；**全卡只有 1 张** featured 高亮卡 |
| 所有数字都发光 | 锚点数字 **≤1 处**发光，其余用纯色粗体 |

## 二、三张旋钮（taste-skill 思路 · 贴图版）

写卡前在心里拧一下（不必问用户）：

| 旋钮 | 贴图默认 | 调高时 |
|---|---|---|
| **版式自由度** | 中：封面可大胆，内页 70% 规整 + 30% 错位 | 封面标题左对齐 + 右侧大数字悬空；内页某块 `ml-6` 或 `w-[92%]` 故意不居中 |
| **视觉重量** | 中：一层背景氛围 + 一层卡片 | 封面加 mono 英文副标 / 背景巨字（opacity 5%）；内页用左边框叙事条 |
| **信息密度** | 按 content-split 规则 | 宁可收紧间距，也不要空白大块 + 底部挤爆 |

**流程图**（gzh-article-html-cards）：版式自由度偏低（节点要对齐），视觉重量用「标题左边框 + 1 个核心节点高亮」即可。

## 三、排版铁律（impeccable 思路 · 静态版）

### 字号阶梯（3:4 贴图）

| 层级 | 字号 | 用途 |
|---|---|---|
| L0 冲击 | 80–150px | 仅封面/结尾一个数字或一句 |
| L1 标题 | 48–56px | 每卡 1 条主标题 |
| L2 区块 | 28–34px | 卡片标题、公式名 |
| L3 正文 | 24–30px | 解释、列表（**禁止 <24px**） |
| L4 元信息 | 22–28px | 标签、页码 |

行高：标题 `leading-[1.1~1.15]`，正文 `leading-relaxed`（≥1.5）。

### 间距（8px 网格）

- 区块间距：`mb-4` / `mb-5` / `mb-6`（16–24px），同一张卡内统一一档。
- 卡片内边距：`p-5`～`p-7`；**禁止** `p-3` 挤成一团。
- 外层：`pt-9 pb-20`（水印安全区，见 design-system）。

### 对比度

- 浅色底正文 `#1C1917` on `#faf8f5`；深色底 `text-white` / `text-slate-100` on `#0a0f1a`。
- **禁止**正文 `text-gray-400/500` 当主色（仅允许元信息 opacity 60–70%）。

### 锚点克制

- 亮橙 `#FF7700`：**每卡 ≤3 处**（一个数字 + 一句金句 + 一个边框，三选一其二即可）。
- 渐变描边：只给 **1 张** `.card-featured` / `.glass-hl`，其余用普通卡。

## 四、版式手法（frontend-design 思路 · 可截图）

**每套贴图至少用其中 3 种**（不要 8 张全用同一种）：

1. **左重标题**：标题左对齐，右侧页码；封面可让数字偏右下 `absolute`。
2. **宽窄错位**：主内容 `w-full`，提醒条 `w-[94%] ml-auto` 或 `mr-8`。
3. **左边框叙事**：`.border-l-4` / `.border-l-[6px]` 引出一个故事块（已在主题 A/B 使用，继续保留）。
4. **编号方块**：渐变方块序号，**不用**细线圈 icon 风。
5. **背景巨字**：一个汉字 `opacity-[0.03~0.06]` 衬底（封面/结尾）。
6. **编辑副标**：封面加一行 `tracking-widest uppercase font-mono text-[22px] opacity-50` 英文装饰（允许）。
7. **密度节奏**：第 2/5/7 张信息满，第 3/6 张留一点气口（不要每张都塞满）。

**禁止**：

- 8 张全是「标题 + 3 列等宽 grid + 底栏」
- 封面与内页除颜色外版式完全相同

## 五、质感层次（高级感而不是塑料感）

每张卡 **2–3 层**即可，不要 5 层特效叠罗汉：

| 层级 | 深色 A | 亮色 B |
|---|---|---|
| 底 | 1–2 个偏移光晕 + noise | mesh 顶区 **或** 暖白底 + 轻 noise |
| 中 | `.glass` 普通卡 | `.card-premium` 描边卡 |
| 顶 | **一张** `.glass-hl` / `.card-featured` | 同上 |

阴影：用 **分层软阴影**（theme B 已定义），不要黑色硬投影 `shadow-lg` 单独糊一层。

## 七、出图前 QA（美学 10 条 + 防裁切 4 条）

**美学**

- [ ] 没用 Inter/Roboto/Arial 当主字体
- [ ] 没有紫/靛大面积渐变背景
- [ ] 正文最小字号 ≥24px（3:4）/ 节点主文案 ≥28px（流程图）
- [ ] 全卡 featured 高亮卡 ≤1 张
- [ ] 亮橙锚点 ≤3 处
- [ ] 本套图中 ≥2 张有明显不对称/错位版式
- [ ] 封面与至少一张内页版式结构不同（不是换字而已）
- [ ] 对比度足够（浅色黑字 / 深色白字）
- [ ] 与金标准（055/056/061）比，**密度和字号同一量级**，不能明显更「空」或更「挤」
- [ ] **底 25% 不是只有水印**：最后一块贴在水印上沿（`.board` + `space-between`，禁止 flex-1）

**防裁切（与 watermark-safe-zone 规则绑定，不可只做美学 QA）**

- [ ] `pb-20` 在**最外层** `1080×1440` div，不是只在内层
- [ ] 内层内容区**无 `flex-1` 撑高**后再堆多卡 + 独立底栏
- [ ] 最后一块（金句/提醒/CTA）**完整可见**，底部有空白再是水印
- [ ] 内容满时先合并底栏/收紧间距，**不要**再加独立 CTA 条
