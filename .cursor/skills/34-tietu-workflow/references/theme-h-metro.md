# 主题 H：地铁线路（Metro Map）

> 成型样例：`workspace/HTMLcards/上滑_2026-09-19_如何分析你所在的行业（地铁）/`  
> 3:4 贴图 CSS：`references/theme-h.css` · 长卷 CSS：`34-eli5-scroll/references/theme-h-long.css`

## 风格定位

浅灰导视图底 + 线路色（红/蓝/青绿/金）+ 圆角站点卡 + 圆形节号。  
像城市地铁图，不是海报叠印、不是石板、不是蓝图网格。
