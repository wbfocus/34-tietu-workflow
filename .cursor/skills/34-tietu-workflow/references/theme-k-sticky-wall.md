# 主题 K：便签墙（Sticky Wall）

> 成型样例：`workspace/HTMLcards/上滑_2026-09-19_财务与业务是什么关系（便签）/`  
> 3:4 贴图 CSS：`references/theme-k.css` · 长卷 CSS：`34-eli5-scroll/references/theme-k-long.css`

## 风格定位

浅暖墙面 + 粉黄蓝便签色块 + 轻微旋转叠放感 + 软圆角。  
像办公室便签墙，活泼，有别于积木乐园（J）的积木阴影，也有别于货柜/地铁。

## 封面

浅色优先 `5 / 6 / 8`；每期换一个，避开最近 2 次。LOGO 不变。

## 与 J 的区别

| | J 积木乐园 | K 便签墙 |
|---|---|---|
| 底 | 米白 + 积木条 | 暖橙浅墙 |
| 形 | 厚描边硬阴影色块 | 便签叠放、轻旋转感 |
| 强调 | 红黄蓝积木 | 粉青琥珀便签 |
