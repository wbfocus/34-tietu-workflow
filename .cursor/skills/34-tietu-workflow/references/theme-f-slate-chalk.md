# 主题 F：石板粉笔（Slate Chalk）

> 成型样例：`workspace/HTMLcards/上滑_2026-09-19_钱收不回来怎么办（石板）/`  
> 3:4 贴图 CSS：`references/theme-f.css` · 长卷 CSS：`34-eli5-scroll/references/theme-f-long.css`

## 风格定位

深绿石板底 + 粉笔黄强调 + 圆角粉笔卡片 + 虚线粉笔框。  
像黑板上刚写完的一课，不是玻璃、Mesh、奶油、蓝图、墨纸。

## 字体（六套共用）

见 [type-shared.md](type-shared.md)。主题 F：

| 类 | 色 |
|---|---|
| `.mark` | `#E8D278`（粉笔黄） |
| `.mark-sage` | `#7DCFB6`（粉笔青绿） |

## 版式

共用 [layout-shared.md](layout-shared.md)。本主题：圆角卡片、内凹微光、虚线原则框。

## 文件夹后缀

## 封面

暗底封面池 `1 / 1b / 2 / 3` 优先，与石板长卷配。

## 与 A / E 的区别

| | A 深色玻璃 | E 墨纸朱印 | F 石板粉笔 |
|---|---|---|---|
| 底 | 近黑玻璃光晕 | 冷灰纸浅底 | 深绿石板暗底 |
| 强调 | 品牌橙/天蓝 | 朱砂红 | 粉笔黄/青绿 |
| 形 | 玻璃模糊圆角 | 墨线直角硬投影 | 粉笔虚线 + 圆角卡 |
